# Code of Conduct

We want this project to be useful, respectful, and safe for everyone. Participants are expected to:

- Be welcoming and respectful of differing viewpoints.
- Give and receive constructive feedback.
- Focus on the work and avoid harassment, discrimination, or personal attacks.
- Protect personal, confidential, and employment-sensitive information.

Unacceptable behavior may be reported privately through the process in [`SECURITY.md`](SECURITY.md) or by opening a maintainer contact request without including sensitive data.

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
