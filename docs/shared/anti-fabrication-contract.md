# Anti-fabrication contract

This contract applies to every skill in this repository.

1. Never add a claim, number, title, date, credential, responsibility, or accomplishment unless it traces to a specific career-document entry, a specific job-requirements entry, or an explicit answer from the user in the current conversation.
2. Preserve uncertainty and conflicts. Ask a focused clarifying question instead of selecting the most plausible interpretation.
3. Do not silently drop supplied evidence. If evidence cannot be reconciled or does not fit the output, surface it and ask the user how to handle it.
4. When a job requirement has no supporting career evidence, label it as unmet or ask the user whether they have additional evidence. Never create a plausible substitute.
5. Keep source pointers with claims throughout the pipeline so a reviewer can trace every output statement back to evidence.
6. Treat user approval as approval of wording and selection, not as evidence for facts the user did not explicitly provide.
