# Security

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability** under **Private vulnerability reporting**.
3. Include the affected commit or file, reproduction steps using synthetic data, impact, and any suggested mitigation.

If private vulnerability reporting is unavailable, contact the maintainer through the email address listed on the maintainer's public GitHub profile. Do not send real resumes, performance reviews, LinkedIn exports, credentials, or other sensitive personal data in a report.

This project is a local Copilot CLI skill bundle. Reports involving prompt injection, unintended data disclosure, unsafe browser behavior, dependency vulnerabilities, or generated-document handling are welcome.
